# 아키텍처와 실제 연결 경계

## 최우선 운영 경로 — 사용자 2026-11-11 선택

1. 출처/기간/조정 의미를 검증한 미국 주식 시세와 독립 구현한 명시 전략 규칙을 수집한다.
2. 독립 엔진이 종가 신호를 다음 거래일 시가에 가상 체결하고 비용·현금·보유·손익을 계산한다.
3. 비공개 영속 가상 원장에 거래일별 입력/전략 버전과 결과를 고정하고 재시작/중복을 대조한다.
4. 자체 모의매매임을 명시한 일일 보고를 기존 비공개 Outbox/Telegram 경로로 보낸다.

현재 `preview-simulation`이 독립 CSV 검사 → 날짜별 명시 신호 → 기존 체결 계산 →
평균원가 일일 보고 미리보기를 연결한다. `preview-sma`는 기존 자체 SMA 연구 규칙에서
가격 기반 신호를 생성해 같은 계산 경로와 연결한다. 명시 창/수량/평가 시작일만 사용하며
최적화·자동 전략 채택은 없다. 생성 manifest는 기존 generic preview와 원장에 인계할 수 있는
명시 날짜별 신호 형식이다. 규칙 ID·창·수량·시작일·라벨/체결 정책의 해시로 자체 버전을 고정한다.
코드 실행/학습/원본 전략 복사는 없으며 가격/수수료 변화를 규칙 버전 변화로 혼동하지 않는다.
`record-simulation`은 같은 계산과 보고 본문을 비공개 거래일별 체크포인트에 불변 저장한다.
명시 bootstrap 이후 정확한 전 NYSE 거래일의 해시 연결·보유·미실행 신호·손익·수수료·
체결 건수를 재시작 때 대조하며 동일 재실행만 허용한다.
시세 원천/전체 인과성 검증과 영속 forward 운영/정기 발송은 미완료다.
초기 가상 현금과 비용은 명시적 계산 가정이며 사용자의 투자금/위험 한도를 설정하지 않는다.
합성 예제는 전략 선정이나 성과 증명이 아니다. 신호 인과성/시세 출처·조정 의미를 검증했다고
주장하지 않고 배당·분할·세금·유동성은 미반영으로 표시한다.
마지막 종가 신호는 미실행으로 남긴다. 기록 명령도 실제 발송하지 않으며 로컬 권한·fsync·
해시는 영속 호스트/백업·시세 진위·전략 승인·암호학적 외부 변조 방지를 증명하지 않는다.
`report_sha256`은 후보 설명까지 포함한 최종 본문 전체에 결합해 원장에 인계한다.

`market_data`는 고정 Alpha Vantage TIME_SERIES_DAILY의 공식 JSON/Compact 응답을
내부 세션 날짜 CSV로 바꾼다. raw-as-traded 가격 형식·US/Eastern 세션 날짜·의도한 종목과
최신 폐장일 및 모든 예정 거래일을 검사한다. 정규화 날짜의 UTC 자정은 내부 라벨이며 체결 시각이 아니다.
`preview-market-sma`는 이 입력을 기존 자체 연구 SMA/일일 미리보기에 연결한다.
HTTPS 1회·15초 I/O timeout·1MB 한도, 리다이렉트/자동 재시도/임의 원천/유료·full 경로 금지를 유지한다.
키는 비공개 호출자 구성이고 공개 로그/CLI 인자/CI에는 넣지 않는다. 2026-11-20 사용자
출력으로 네이버 호스트의 개인 무료 키 IBM/SPY 일봉100개·최신일 검사를 확인했다.
최근100개 창을 고정 이력으로 잘못 대체하지 않는다. 아카이브·원장·Outbox 연결 코드는
아래와 같이 구현됐지만 실제 forward 기록과 일일 수신은 미완료다.

`research_indicators.daily_indicators`는 같은 DailyHistory/예정 폐장 세션 계약을 공유하는
자체 일봉 지표 입력이다. 명시 EMA/RSI/ATR/ATR 평균 기간, seed와 Wilder 재귀를 사용하며
warmup 및 평탄 RSI 미정의 값은 None이다. 기본 운영 기간/규칙/비중/주문은 선택하지 않는다.
고정 이력 시작일 변경은 재귀 seed를 바꾸므로 이동 Compact 창의 결과를 forward 원장으로
승격하지 않는다. 원본은15분봉/on-close/진입가 보호 주문으로 확인돼 현재 다음 시가 일봉
엔진과 비동등하다. 일봉 후보는 별도 연구 가설이며 원본 재현·전략 승인으로 표시하지 않는다.

`research_reversal.reversal_close_decisions`는 자체 일봉 지표에서 필수 입력된 RSI/EMA/ATR
조건으로 고정 수량 진입을 생성한다. 보유 중 종가 손실→종가 이익→보유 세션 수→RSI 청산
순으로 판단하고 필수 지표 미정의 시에는 진입 차단/보유 청산을 우선한다. 모든 신호는 다음
정규장 시가에만 체결한다. 손익 기준은 관측한 진입 시가와 매수 슬리피지이며 수수료는 기존
회계에 별도 반영한다. 장중 고가/저가의 임계값 접촉을 보호 체결로 바꾸지 않는다. 갭으로
청산 기준보다 큰 손실이 날 수 있고 진입 체결일도 보유1세션으로 센다. 청산 체결일의
재진입은 금지하고 추가 매수/공매도는 생성하지 않는다. 이 의미는 별도 규칙 ID로 고정한다.

`independent_reversal.preview_independent_reversal`/`preview-daily-reversal`은 명시 비공개
설정/CSV에서 신호 manifest→기존 평균원가 회계→최종 설명 포함 본문 해시를 반환한다.
규칙/seed/라벨/체결·슬리피지를 버전에 결합하며 초기 가상 현금/수수료는 회계 범위에 둔다.
CLI는 유한 입력/중복 JSON/무비밀 인자 오류/Public CI 파일 접근 전 차단을 공유하고 발송·저장은
하지 않는다. 합성2세션 원장 인계/재시작을 확인했으며 아래 통합 경로는 별도 명시 스키마로
후보를 지정한다. 실제 후보 운영 승인을 부여하지 않는다.

Astral 외부 인증/회계·체결 문의는 별도 보류 항목이며 이 독립 경로를 막지 않는다.
기존 Astral 경로(공식 미리보기 승인 후 Paper 배포 → 공식 MCP 조회 → 회계 대조 →
Telegram)는 유지한다. `astral.py`는 공식 structuredContent 선택·검증 함수이며
인증 SDK가 아니다. ChatGPT OAuth 토큰 추출이나 API URL 추측을 허용하지 않는다.

## 네이버 클라우드 운영 연결 — 사용자 최신 선택

자체 엔진의 동일 paper_worker를 네이버 Linux 호스트에서 비root Docker 컨테이너로
실행하는 설정을 준비한다. bind 저장소와 root 전용 env-file을 사용하며 외부 수신 포트,
Docker socket, 자동 이미지 pull/자동 재시도는 없다. prepare.sh는 처음 설치만 수행하고
서비스 시작/활성화는 하지 않는다. host_storage는 빈0700 저장소를 배타 선점해 한 번만
초기화하며 실패 흔적은 보존한다. inspect는 읽기 전용 구조/control/큐 점검으로 실제
회계·시세·수신 검증과 구분한다. 모바일 절차는 docs/NCLOUD.md를 따른다.
NYSE 폐장90분 뒤 기존 단일 실행·영속 attempt/complete와 불명확 상태 차단을 유지한다.
사용자 출력으로 실제 서버 설치·Docker 준비·고정 Telegram 점검 sent와 개인 수신을
확인했다. 재부팅 영속성·상주 메모리 충분성·실제 Paper 일일 수신은 미검증이다. 이전 Render 구성은 참고용으로
보존하며 이중 운영하지 않는다. Astral 회신은 운영의 선행 조건이 아니다.

## 역할별 구성과 권한

이미 운영 승인을 받은 호출자는 `run_market_paper`에 전송기와 명시 opt-in을 공급해
새 보고만 1회 시도할 수 있다. Outbox.enqueue는 삽입 트랜잭션 commit 후 생성 여부를
반환하므로 동시 호출 중 삽입자만 deliver를 호출한다. 이전 pending도 자동 전송하지 않는다.
삽입 후 중단은 pending, 전송 결과 불명확은 unknown/sending으로 보존해 운영자 대조한다.
이 연결은 기본 꺼짐이며 CLI/공개 CI/실제 스케줄을 활성화하지 않는다. 고정 점검 수신은
확인됐지만 실제 Paper 일일 수신은 미검증이다.

비공개 `run-paper` 명령은 기존 수집/원장/큐 모듈을 단일 실행으로 연결한다. 명시 설정과
저장소 준비를 확인한 뒤 공식 시세를 최대1회 조회한다. 같은 거래일 원장이 있으면 조회/
재계산을 생략하고 저장 본문의 인계만 대조한다. 종가 경계/1분 초과/시계 역행에는 기록을
차단한다. 결과는 거래일·수집 여부·큐 상태만 반환하며 발송/스케줄/새 인증 권한은 없다.

`paper_outbox.enqueue_latest_paper_report`는 최신 저장 보고의 해시/실행 범위/전일 연결을
검사한 후 기존 Outbox의 불변 삽입/대조 트랜잭션에 같은 본문을 전달한다. 자체 Paper 키는
실행 범위/시작 거래일/보고일에 결합하며 Astral 보고와 구분한다. 원장과 큐는 별도 저장소다.
중단 후 동일 인계는 큐 상태를 유지하며 pending/sending/unknown은 운영자 확인 대상이다.
실제 발송/재시도/비밀 접근은 없다. 원장은 읽기만 하며 Outbox를 자동 생성하지 않는다.

`paper_pipeline.record_archived_sma`는 명시 후보 설정→비공개 시세 누적→SMA 신호→Paper
체크포인트를 연결한다. 첫 거래일은 평탄한 현금 기준선이며 해당 종가 신호는 다음 시가에만
반영한다. 평가 시작일은 bootstrap 날짜와 같아야 하고 규칙/비용/가상 현금은 고정 저장한다.
아카이브와 회계는 독립 저장이며 계산 실패 시 이미 저장된 시세는 남겨 동일 재시도에 사용한다.
연구 비교는 기존의 다음 시가 자료 필수 조건을 유지한다. 후보 기록은 채택/실제 운영 증명이 아니다.

`record_archived_candidate`는 닫힌 스키마 분기로 기존 SMA 또는
`archived_reversal_record_v1`의 별도 일봉 후보를 같은 아카이브/원장 경로에 연결한다.
`record_archived_reversal`도 제공하며 기존 SMA 함수/핀 이름은 호환된다. 공통 설정 핀으로
서로 다른 후보 종류의 동시 초기화도 선점하고 종류별 핀을 유지한다. 공통 핀이 없는 legacy
SMA는 재시작 때 기존 핀으로 대조하고 다음 기록 때 같은 공통 핀을 추가한다. 설정을 가격 저장
전에 불변 고정하고 첫 bootstrap도 기존 다른 후보/미대조 파일을 인수하지 않는다. runtime은
이 핀과 준비 관측 수를 먼저 검사한다. 반전 후보의 최소 관측은 max(EMA기간, RSI기간+1,
ATR기간+ATR평균기간)이며 Compact100개로 불가능하면 조회하지 않는다. 실제 응답이 짧으면
저장 전에 중단한다. 아카이브는 고정 시작일을 보존해 재귀 지표 seed를 유지한다.
run-paper와 기존 단일 Worker가 이 명시 분기를 재사용한다. 기록된 같은 날은 조회/재계산 없이
원문 큐 인계만 대조하고, 기존 pending/sending/unknown/sent는 새로 발송하지 않는다.
부분 저장은 지우거나 자동 초기화하지 않는다. 이미 승인된 호출자의 신규 보고1회 전송만
기존 방식대로 허용하며 실제 서버 플래그·후보 선정·예약·운영 위험 설정은 변경하지 않는다.

`price_archive.PriceArchive`는 정규화된 Compact 입력을 별도의 비공개 거래일별 스냅샷으로
누적한다. 첫 시작일은 고정하고 매일 정확한 전 NYSE 거래일의 저장 이력과 겹치는 OHLCV를
대조한다. 창에서 빠진 과거 행은 유지하며 변경/누락/겹침 부재에는 중단한다. 기존 Paper
원장의 POSIX 비공개·불변 저장 검사를 공유하지만 파일 이름 공간과 디렉터리는 분리한다.
실제 영속 호스트·백업/자동 수집 연결/회계 원장/발송은 별도 미완료다.

| 독립 검증 | 규칙·거래·비용 → 승격 판정 | ② 공통 오프라인 검증 실행기: 자체/공개 동일 회계·재실행·terminal prefix·단일 비용 스트레스, 전체 승인/실제 성과 미검증 | 없음 |
| 실행 | 독립 규칙/시세 → 가상 체결·가상 원장 | 명시 SMA/반전 후보를 공통 runtime에 연결; 호스트 Worker 기동·첫 현금 기준선 보고 확인; 다음 거래일 체결/복구 미검증 | 실제 주문 없음 |
| 보고 | 자체 가상 손익/저장 보고 → Outbox → Telegram | 네이버 고정 점검1건 sent·개인 수신 확인, 첫 기준선 일일 보고 실제 수신 사용자 확인; 지속·중복·복구 미검증 | 없음 |

분석 역할의 별도 유료 AI 호출/상주 프로세스는 추가하지 않는다. 실행은 검증·승인 후 네이버 호스트의 단일 Worker를 사용한다. 운영 중인 전략은 연구
후보와 별도로 관리하며, 높은 백테스트 수익만으로 자동 승격하지 않는다.

공개 탐색은 초기 검색·조회만 사용한다. 자체/공개 후보는 같은 독립 검증 기준을 적용하며
성과 기간·비용·체결 의미·과최적화·자료 품질·재현성과 Paper/백테스트 구분을 보존한다.
확인할 수 없는 버전/지표를 만들지 않는다. 중복 수집·검증을 막고, 저장/복사는 필요한 때만
별도로 활성화한다. 주간 탐색의 호출 제한/중복 방지 코드는 구현됐지만 주간 자동화는 아직 등록/활성화하지 않았으며 매시간 개발 예약과 다르다.
구현 순서는 Paper·Telegram MVP → 공개 탐색 → 공통 검증 → 조건부 전략 선택이다.

## 확인된 공식 인터페이스

기존 Astral 경로에 관한 사용자 2026-11-10 선택으로, 완전한 매매 보고 전에 확인된 계좌·배포 상태만 알리는
제한 보고 단계를 둔다. 알림 날짜는 한국 시간 기준이며 거래일/종가 평가를 뜻하지 않는다.
손익·체결·평가액·보유·위험 한도는 미확인으로 유지하고 별도 Outbox 키를 사용한다.
공식 원장 대조 없는 매매 성과 보고를 허용하는 변경이 아니며, 전략 배포와 실제 운영
연결은 여전히 미완료다. 공개 탐색은 완전한 Paper·Telegram MVP 이후라는 순서를 유지한다.

status_runner.run_account_status는 이미 인증된 공식 MCP 콜백으로 계좌/배포를 각각1회
읽고 기존 정규화/렌더링과 비공개 Outbox 전송을 연결한다. 초기화된 원장을 먼저 검사해
같은 한국 날짜의 기존 기록이 있으면 조회/발송을 생략한다. pending/sending/unknown은
운영자 확인 대상이다. 동시 최초 수집은 겹칠 수 있으나 본문 불변/원자적 발송 선점으로
중복 발송을 차단한다. 한국 자정 경계/5분 초과/시계 역행/불완전 응답은 저장 전에 차단한다.
읽기 전용 inspect-outbox는 pending/sending/unknown을 미완료로 집계해 운영자 확인 필요와
종료 코드2를 반환한다. 원장/본문 수정이나 자동 재전송을 하지 않으며 조회 시점의 집계만 제공한다.
계좌/배포 수집은 Python3.11 TaskGroup으로 묶어 한쪽 조회 실패 시 나머지 조회를 취소하고
정리까지 기다린다. 호출자 취소도 정리 후 전달하며 제공자/정리 오류 원문은 공개하지 않는다.
연결 콜백의 협조적인 취소/자체 전송 정리가 전제이며 원격 서버 요청의 철회까지 보장하지 않는다.
collect_preflight와 collect_activity의 각 병렬 단계도 실패한 형제 조회의 취소·정리까지
기다린다. 활동 수집은 계좌/배포 검증 후에만 주문/거래 이력 단계를 시작하며 부분 결과를
정상 관측으로 반환하지 않는다. 제공자/정리 오류 원문은 고정 오류로 숨긴다.
Public Actions에서는 시계/파일/네트워크 접근 전에 거부한다. 이 통합 함수는 인증 브리지,
자동 스케줄 또는 운영 호스트가 아니며 실제 계좌 알림 수신도 아직 확인되지 않았다.


- 전략: astral_strategy_build / astral_explore_save / astral_saved_strategy_save
- 백테스트: availability → start → status → 완료한 정확한 ID의 get
- 배포: deploy_preview → 실제 미리보기 승인 → deploy
- 관측: broker_accounts_list / deployments_list / portfolio_positions /
  order_list / trade_history / strategy_event_log / equity_curve
- 전달: Telegram HTTPS Bot API sendMessage. Astral 내장 알림의 Telegram 지원은 확인되지 않았다.

지원 증권사는 공식 문서와 개별 계정의 실행 가능 범위를 함께 확인한다.
공식 목록에는 Alpaca Paper, E*TRADE, moomoo, tastytrade, Public, Webull US 등과
일부 가상자산 연결이 표시된다. 토스증권은 확인한 공식 목록에 없다.
문서의 가상자산 지원 설명과 표에 차이가 있으므로 미래 실거래 지원을 단정하지 않는다.
현재 연결된 계정은 Paper뿐이며 새 실계좌를 연결하지 않았다.

전 거래일 누락을 임의 보정하지 않는다. 계산 검증과 원천 확보/진위 검증은 별개다.

## 공개 전략 탐색의 독립 수집·검증 인계 모듈

public_discovery.run_public_discovery는 총괄이 공급한 공식 비동기 MCP 콜백만 사용한다.
enabled=False와 mvp_verified=False가 기본값이다. 호출자 확인 플래그는 MVP/성과 증명이 아니며
현재 Worker·서버·개발 예약·주간 자동화에 연결하지 않는다. 검색은 newest 정렬1페이지/최대5개,
상세 조회는 별도 확인된 미국 주식 범위의 후보에만 최대5회다. 인기/수익률 필터·순위화가 없다.
has_more를 more_available로 보존하고 completed_bounded_page는 이 제한된 페이지의 성공이지
전체 Explore 탐색 완료가 아니다. callback 이름은 astral_explore_search/get 둘뿐이며 저장·복사·
백테스트 실행·주문·배포·비밀 획득 권한이 없다. 원본 텍스트는 지시가 아니라 입력 자료다.

운영 원장과 분리된 기존 소유자0700 디렉터리를 명시 공급한다. 기존 비공개 불변 저장 검사와
0600/fsync를 재사용한다. 공통 실행 순번의 attempt를 외부 호출 전에 선점해 다른 시각/검색어의
동시 호출도 한 개만 진행한다. 직전 시작168시간 전에는 조회하지 않는다. 실패/중단·불완전 파일은
다음 주에도 자동 재시도/초기화/삭제하지 않는다. 완료 파일 하나가 후보와 인계의 commit이다.
완료 직후 중단돼도 read_public_candidates로 신규 조회 없이 인계 목록을 재구성한다.
파일 소유권/해시는 로컬 모순 검사이며 외부 공격자에 대한 인증이나 실제 호스트 복구 증명이 아니다.

공개 publication ID/출처·공개 작성자·조회/게시 시각, 봉/체결 의미, 명시 기간/자금/비용과 보고된
성과를 기록한다. 검색/상세/상세 wrapper 지표를 분리하며 누락 값은 None이다. 백테스트 지표를
실제 Paper 성과로 변환하지 않는다. 원본 전체 소스/가격/계좌·사용자 ID/저장 전략 ID/서명 URL은
저장하지 않고 관측한 정의의 해시만 보존한다. 이 해시나 payload.v=2를 제공자 전략 버전으로
표시하지 않는다. 제공자 버전은 미확인이다. 완전한 정의/조건/성과의 관측 증거가 같으면 재분석을
생략하되, 목록에 버전이 없으므로 주간 상세 재조회는 필요하다. 정의도 없으면 같다고 단정하지
않고 change_unconfirmed/출처 재확인 대상으로 남긴다. 중요 변경은 별도 인계한다.

payload.strategy.universe.assets의 id를 symbol로 해석하여 공개 자산 목록과 대조하고,
datasets.assets 참조와 kind=ohlcv의 명시 timeframe을 engine.bar_size와 대조한다. 데이터셋
이름이나 ID로 종목/봉을 추측하지 않는다. 잘못된 참조·명시 충돌은 고정 오류로 인계 전에
차단하고 attempt를 남긴다. 미제공 범위/봉/분류/통화는 미확인, 제공자 비-equity/비-USD는
검토 표시다. 분류 메타데이터는 독립 시장 확인이 아니며 신호 내부 참조·규칙 의미는 미검증이다.
v1 필드와 중요 변경 digest 계약을 유지한다. 진단 코드 갱신만으로 기존 비공개 journal/인계
본문을 재작성하거나 같은 증거를 재인계하지 않는다. 기존 인계는 새 검사를 소급 통과하지 않는다.

유지한다. 자체/공개 출처 모두 규칙·기간·비용·체결·자료 품질·위험·재현성·forward Paper 확인이

## 공통 독립 검증 실행기와 역할별 개발 재개

independent_validation.validate_candidate는 기존 명시 SMA/일봉 반전 spec과 private CSV를
받아 동일 폐장 세션·다음 시가 회계·정확 재실행·마지막 세션 제거 시 이전 신호 불변을 검사한다.
최대2048행, 최대4회 규칙 평가이며 선택적 비용 스트레스1개는 두 비용을 명시하고 낮추지 않는다.
반전 신호도 변경된 슬리피지로 다시 계산한다. 비용 증가가 수익 감소를 보장하지 않는다.
공개 후보는 기존 v1 인계를 그대로 추가 입력하며 봉/체결/종목 비동등이면 held,
누락/출처 갱신 필요는 insufficient로 보류한다. 제한 필드가 맞아도 원본 규칙 재현 증거가 아니다.
source_execution의 next_session_open 호환 표시는 합성 계약이며 Astral 지원을 인증하지 않는다.

결과는 named check의 passed/held/insufficient와 계산 해시·조건·손익 집계이며 원본 가격/
신호 행/원본 소스/보고 본문은 출력하지 않는다. data_kind는 synthetic/historical만 허용하며
forward 실적은 지원하지 않는다. 완료 왕복 수·샤프·승률·연환산은 None이다. 체결 수는 주문
단위이고 수익 분모는 가상 초기 현금 전체다. 전체 출처·조정·인과성·검증기간·선정 이력·
과최적화·표본·위험·실제 Paper 근거가 부족해 전체 상태는 통과/배포 승인을 만들지 않는다.
Worker에서 import/호출하지 않는 별도 연구 실행기이며 네트워크·파일·원장·전송 권한이 없다.

## 뉴스 출처·시점 보존 입력 계약 (운영 미연결)

news_evidence.evaluate_news(records, as_of, max_age, collection_status)는 닫힌
news_evidence_v1 메타데이터를 불변 NewsBatch/NewsAssessment/NewsEvidence로 반환한다.
같은 기존 aware timestamp 파서를 사용하며 발표/관측/사건일/대상기간/예정 시각을 분리한다.
최대100개/정규화 누적256000바이트, 제목300자/요약 최대800자이며 전체 기사·경제 수치·
예상/이전/실제값을 받지 않는다. None은 미확인으로 보존하고 naive 시각은 임의 보정하지 않는다.
관측이 as_of 이후인 자료는 제외한다. 신선도는 발표+명시 max_age에서 만료하며 재관측으로
늘리지 않는다. max_age는 양수/최대30일의 호출자 연구 가정이지 운영 위험 한도가 아니다.

동일 source/document/version·내용의 가시 재관측만 가장 이른 관측으로 중복 제거한다.
같은 ID의 상충 내용과 여러 가시 버전은 모두 보존/보류하며 정정본을 자동 선택하지 않는다.
예정 공지가 예정 시각을 지났다고 실제 발표로 바뀌지 않는다. 부분/실패/빈 입력·오래됨·누락·
미확인/정정/상충은 정상 시장 상태가 아니다. 명시 event 연결은 보존하되 출처 간 기사 병합·
사건 수 추정·자연어 의미 충돌 판정은 하지 않는다. 이미 아는 충돌은 호출자가 표시해야 한다.

ready_for_research/eligible_for_research와 release_notice_available은 이 제한된 검사만
뜻한다. source_authenticity_verified/deployment_approved는 false이며 출처 진위·기사 진실·
경제 수치·시장 합의·투자 판단/전략 검증을 증명하지 않는다. ① 코드 통합 검토와② 소비 계약
검토를 구분한다. ② 제한 메타데이터 소비 경계 검토는 완료했고 실제 어댑터/전략 통합은
미검증이다. 내용 digest만으로 적격성을 캐시하지 않고 as_of/max_age/collection_status와
최초 관측/버전·정정 근거를 평가 기록에 함께 보존한다. 기존 Worker에 강제로 연결하지 않는다.
HTTPS/인증부·포트·쿼리·fragment 제한은 모든 비밀/개인정보 제거 보장이 아니다.
repr/오류는 외부 내용을 숨기지만 실제 입력/출력은 이용 권리 확인 전 비공개로 유지한다.
