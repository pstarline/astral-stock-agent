  원격 저장소가 없으면 astral-stock-agent-initial.zip의 현재 버전으로 상태를 복구한다.
- 기존 Auto-Stock 예약 2개는 비활성 상태였으며 변경하지 않았다.

## 리소스

새 유료 서비스/서버/API 결제는 하지 않았다. 현재 Astral 계정이 허용한
Paper와 기존 백테스트 기능만 사용했다. 백테스트 실행은 총 2회다.
Astral은 일일 백테스트 limit=-1(제한 없음)을 표시한다. remaining=999999는
무제한 상태의 표시값이므로 실제 남은 횟수로 보고하지 않는다.
GPT-Work 잔여 사용량과 GitHub 계정 잔여 사용량은 조회하지 못했다.
Public 표준 Actions 무료 범위는 공식 문서로 확인했으나 실제 실행은 미검증이다.
